# 🎯 InterviewIQ.AI

### AI-Powered Mock Interview Platform

InterviewIQ.AI is a full-stack AI-powered interview preparation platform that simulates realistic mock interviews and provides personalized performance feedback based on the user's resume, skills, and experience.

🔗 **Live Demo:** https://interviewiq-ai-1-client-ww5q.onrender.com

---

## 🚀 Features

* 🔐 **Google Authentication** — Secure login using Firebase + JWT
* 📄 **Resume Analysis** — Extracts relevant skills, experience, projects, and role information from uploaded resumes
* 🤖 **AI Interview Questions** — Generates personalized questions using an LLM via OpenRouter
* 🎤 **Voice-Based Interviews** — Speech recognition and text-to-speech for an interactive interview experience
* ⏱️ **Timed Interviews** — Simulates real interview pressure with question timers
* 📊 **AI Performance Reports** — Evaluates answers based on correctness, communication, confidence, and overall performance
* 📚 **Interview History** — Stores and displays previous interview results
* 💳 **Credit System** — Credit-based access to AI-powered interview generation
* 📱 **Responsive UI** — Modern React-based interface

## ⚙️ Run Locally

### Clone

```bash
git clone https://github.com/piyush1066/InterviewIQ.AI.git
cd InterviewIQ.AI
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

Create a `.env` file in the server directory with your MongoDB, JWT, OpenRouter, and Firebase configuration.
